# Flule34

Flule34 是面向 Android 的 Rule34Video 第三方 Flutter 客户端。它直接使用网站现有页面、接口和视频源，重点改善移动端的内容筛选、视频播放、下载与本地整理体验。

本项目与 Rule34Video 官方无关，仅供已达到所在地法定成年年龄、且所在地区允许访问相关内容的用户使用。

## 主要功能

### 浏览与筛选

- 首页提供最新、热门、高评分和关注内容；
- 首页支持单列和双列视频布局；
- 支持搜索视频、标签、分类、艺术家和上传者；
- 可组合标签、艺术家、分类、内容取向、时长和发布时间等条件；
- 支持最低点赞率、最低投票数、排除条件和多条件交集；
- 视频卡片统一展示发布时间、浏览量、点赞率、票数和时长。

### 播放体验

- 默认优先播放 1080P，不存在时自动选择较低的最高清晰度；
- 支持网站提供的 2160P 视频源；
- 持久化视频缓存、播放进度、倍速和清晰度偏好；
- 拖动到已缓存位置可快速恢复播放，未缓存位置会从目标点重新加载；
- 全屏进入默认隐藏控件，退出后立即恢复普通播放器控件；
- 支持保持设备方向或强制横屏；
- 支持后台播放、屏幕常亮和循环播放。

### 媒体库

- 网站收藏、观看历史和艺术家/上传者订阅；
- 与账号无关的本地分类库，可创建自定义库并自由添加或移出视频；
- 内置 HydraFXX、Nagoonimation、Bamh3D、JuicyNeko 和 Drills3D 作者精选库；
- 本地分类库、收藏和历史均支持搜索与筛选；
- 账号播放列表支持创建、重命名、管理视频和沉浸式连续播放；
- 播放列表支持顺序播放、列表循环、单集循环和下一集预缓存。

### 下载与账号

- 视频固定下载到公共目录 `Download/Flule34`；
- 支持后台下载、通知、暂停、继续、失败重试和任务恢复；
- 下载记录会校验公共文件，外部删除、改名或体积变化后会标记为失效；
- 支持仅删除记录、清理失效记录以及批量删除记录和文件；
- 登录 Cookie、账号和密码可保存在 Android 安全存储中；
- 会话失效时会尝试自动恢复登录，不影响公开内容播放。

### 中文翻译

- 内置标签和分类词表，并支持用户手动修改或补充译文；
- 中文翻译库统一管理内置、API 和用户译文，支持搜索、分类、排序、编辑和批量管理；
- 翻译库支持版本化 JSON 导入和导出；导入只合并 API 与用户译文，不覆盖 App 内置词表；
- 可配置多个 Chat Completions、Responses、Anthropic、DeepL 或 MyMemory 服务，并按顺序自动兜底；
- AI 服务首次使用时会自动选择“关闭思考、最低思考或默认行为”，成功策略按服务长期缓存，后续请求不再重复测试；
- 自动翻译按标题、分类、标签分别勾选，默认全部关闭；
- API 翻译结果会长期保存为本机已学习译文，不会因 Provider 变化、普通缓存清理或内置词表更新而丢失；
- 双语显示使用结构化分隔线，视频标题、标签和分类会自适应换行，双列视频流使用瀑布流布局；
- 中文搜索会同时尝试网站原生搜索和已学习标题的英文反查，并合并去重。

## 安装

前往 [GitHub Releases](https://github.com/Hanestl/Flule34/releases/latest) 下载最新的 `arm64-v8a` APK。

Flule34 仅发布 Android ARM64 版本，适用于绝大多数现代 Android 手机和平板。最低支持 Android 7.0（API 24）。安装侧载 APK 时，Android 可能要求为浏览器或文件管理器开启“安装未知应用”权限。

建议同时下载 Release 中的 `SHA256SUMS.txt` 校验安装包完整性。

## 数据说明

- 本地分类库和下载记录保存在设备上，与网站账号无关；
- 网站收藏、历史、订阅和播放列表与当前登录账号关联；
- 下载完成的视频位于公共目录，卸载 App 不会自动删除；
- App 不集成广告、分析或第三方崩溃上报 SDK；
- 本地诊断日志自动脱敏并仅保留最近 7 天，可在“隐私与数据”中导出或清除，绝不自动上传；
- 播放器再缓冲时在画面中央显示圆形加载指示器；
- 详细说明见 [PRIVACY.md](PRIVACY.md)。

## 本地构建

已验证的构建环境：

- Windows 11 或 Linux；
- Flutter 3.44.8；
- Dart 3.12.2；
- JDK 17；
- Android SDK 36。

```powershell
flutter pub get
dart run build_runner build
flutter analyze --no-pub
flutter test --no-pub
flutter build apk --release --split-per-abi --target-platform android-arm64 --no-pub
```

APK 输出到：

```text
build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
```

数据库结构发生变化时，还需要同步更新 `drift_schemas/` 中的迁移快照与测试。

## 已知边界

- 列表、详情和账号功能依赖网站 HTML 结构，网站改版后可能需要同步更新解析器；
- 视频地址包含具有时效性的访问参数，播放器和下载会在必要时重新获取来源；
- `better_player_plus 1.3.4` 仍使用传统 Kotlin Gradle Plugin 配置，当前固定 Flutter 版本可以正常构建；
- 本项目不会绕过网站权限、付费限制或地区限制。
