# ADR-0006：下载与账号本地数据的安全清理

- 状态：已接受，真实设备文件系统回归仍待完成
- 日期：2026-07-24

## 背景

下载记录同时存在于三个位置：后台下载插件数据库、App 的 Drift 数据库和 Android App 私有文件目录。只删除其中一处会形成残留文件、幽灵任务或界面记录。账号本地数据清理还需要删除播放进度，但不得影响网站收藏和账号资料。

## 决策

### 单条下载删除

删除顺序固定为：

1. 验证下载记录属于当前登录账号；
2. 验证插件任务目录与 `downloads/<userId>` 一致；
3. 取消活动任务，由插件清理可恢复临时文件；
4. 验证最终文件路径位于当前账号下载目录；
5. 删除最终文件和插件任务记录；
6. 只有前述步骤成功后才删除 Drift 下载记录。

文件系统或目录验证失败时保留 Drift 记录，使用户仍能看到问题并重试，不制造不可追踪的磁盘残留。

### 账号本地数据清理

- 仅在登录状态下执行；
- 逐条执行上述下载删除流程，允许部分成功；
- 成功删除的任务立即移除 Drift 记录，失败记录保留；
- 下载处理完成后删除当前账号的播放进度；
- 保留 `UserAccounts` 主记录和当前会话，避免清理后新建账号数据触发外键错误；
- 不调用网站接口，因此网站收藏、播放列表和账号资料不受影响。

### UI

- 每条下载提供删除按钮和不可撤销确认；
- 活动任务的确认文案明确说明会先取消任务；
- 隐私与数据页提供当前账号本地数据清理；
- 批量清理返回成功与失败数量，不把部分成功伪装成完整成功。

## 验证

- Repository 测试验证平台文件清理先于 Drift 记录删除；
- 测试验证账号清理删除下载与播放进度但保留账号主记录；
- 全部 17 条自动化测试通过；
- Flutter 静态分析通过。
