# ADR-0007：账号绑定的播放恢复与视频地址刷新

- 状态：已接受，真实设备令牌过期回归仍待完成
- 日期：2026-07-24

## 背景

视频直链包含有时效性的访问令牌。播放器还需要在切换清晰度、离开页面或 App 生命周期变化时保留观看位置，并且播放进度必须遵守既定账号边界。

## 决策

### 播放进度

- 新增 `PlaybackRepository`，页面不直接读写 Drift；
- 只有登录状态且开启“记忆播放进度”时才读取和保存；
- 播放期间每跨越约 5 秒持久化一次，切换清晰度和退出页面时立即保存；
- 进度低于 5 秒时不自动恢复；
- 距离结尾不超过 15 秒时将恢复位置归零，避免每次打开都跳到片尾；
- 数据按稳定用户 ID 和视频 ID 隔离。

### 清晰度切换

- 新控制器初始化前记录旧控制器的位置和播放状态；
- 新来源初始化后设置循环策略、恢复位置，再根据旧状态继续播放；
- 控制器替换使用递增操作编号，过时的异步初始化结果会被丢弃并释放。

### 视频地址刷新

- 初始化失败或运行中进入 `hasError` 状态时，重新加载视频详情；
- 优先选择与失败来源标签相同的新来源，否则按默认播放清晰度选择；
- 重新获取当前 Cookie，并在新控制器中恢复位置；
- 保存已经失败的 URL，拒绝对同一地址自动无限重试；
- 手动“刷新并重试”会开始一次新的显式尝试；
- 刷新时保留错误前最后一次播放状态。

## 验证

- Playback Repository 测试覆盖账号隔离、断点恢复、片尾归零和关闭进度记忆；
- 设置持久化测试覆盖进度记忆选项；
- Flutter 静态分析通过；
- 全部 20 条自动化测试通过。
