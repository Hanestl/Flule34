# ADR-0018：分页结束语义、发现目录搜索与媒体库范围

- 状态：已接受
- 日期：2026-07-25
- 部分取代：ADR-0008 的媒体库一级页签

## 背景

网站部分列表在末页之后返回 HTTP 404，而不是空列表。发现目录同时混用了普通路径分页、AJAX Block 分页和仅过滤已加载项目的本地搜索，导致末页报错、标签目录进入错误页面以及全站实体无法找到。媒体库六个页签也产生了功能重复。

## 决策

- 分页视频列表仅在第二页及以后把 HTTP 404 规范化为空页；第一页 404 仍作为真实错误；
- 标签目录第二页起调用 `list_tags_tags_list` AJAX Block，分类和艺术家继续使用各自页面分页；
- 标签、分类和艺术家目录搜索调用网站 JSON 接口，统一使用 `q`，标签和分类附加 `id=true`；
- 搜索采用 300 毫秒防抖和操作序号，旧请求不得覆盖新关键词；
- 频道当前没有可用搜索接口，保留本地筛选且空列表后不再翻页；
- 媒体库一级页签只保留收藏、历史和订阅；播放进度恢复、稍后观看读取和播放列表 API 可以保留为底层能力，但不占用一级导航。

## 结果

- 正常到达末页不再显示错误和重试按钮；
- 输入 `tifa` 等尚未加载到本地的关键词时可以查询全站标签；
- 发现目录的分页 URL 不再与实体详情 URL 混淆；
- 媒体库信息结构更紧凑。
