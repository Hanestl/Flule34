# ADR-0017：公共目录直写与持久播放器

- 状态：已接受
- 日期：2026-07-25
- 取代：ADR-0004 的账号下载边界、ADR-0013 的私有目录导出流程、ADR-0012 的旧控制层实现

## 背景

验证版把下载文件先写入 App 私有目录，再由用户导出到公共目录；详情播放器随信息列表滚动销毁，控制层较厚，缓存和后台行为也不稳定。下载文件本身不属于网站账号数据，继续按账号隔离会增加协调、迁移和存储成本。

## 决策

- 下载使用 `background_downloader` 的 `UriDownloadTask`，直接写入 Android SAF 授权目录；
- 首次下载默认请求 Downloads 授权并创建 `Flule34` 子目录，设置中允许选择其他目录；
- 下载任务使用设备级数据库归属，只保存暂停、重试、取消、播放和删除所需的最小状态；
- 网站收藏、稍后观看、历史和播放进度继续按登录账号隔离；
- 详情播放器使用 `better_player_plus`，启用 ExoPlayer 持久缓存、媒体通知和前台播放服务；
- 播放器固定在详情页顶部，控制层保持透明单行，清晰度与倍速分别选择；
- 后台播放默认关闭，由用户在播放设置中显式开启。

## 结果

- 用户可以直接在文件管理器中找到下载文件；
- 退出或切换网站账号不会影响本机下载；
- 页面滚动、进度拖动和短暂切换应用不再导致播放器实例频繁重建；
- Android 目录权限失效时必须要求用户重新授权，不静默回退到私有目录。
