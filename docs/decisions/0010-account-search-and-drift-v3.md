# ADR-0010：成熟搜索闭环与账号隔离 Drift v3 历史

- 状态：已接受
- 日期：2026-07-24

## 背景

原搜索页只能请求第一页视频和标签建议，没有排序、筛选、结果类型、自动分页或历史记录。产品架构要求搜索历史不得跨账号混用，未登录状态首版也不得持久化匿名历史。

站点搜索参数分散在页面 HTML、JSON 自动补全端点和前端脚本中，因此不能只根据字段名称猜测协议。

## 决策

### 搜索领域模型

- `SearchResultScope` 提供综合、视频、标签、艺术家和分类结果范围；
- `VideoSort` 同时服务发现集合与搜索结果；
- `ContentOrientation`、`UploadPeriod` 和 `VideoDurationPreset` 表达核心筛选；
- `SearchSuggestion` 统一标签、分类和艺术家建议，并可转换为内容集合；
- `SearchFilters` 是不可变筛选快照，负责驱动请求和页面重建。

### 已验证请求协议

- 标签：`tags_json.php?id=true&advanced_search=true&term=...`；
- 分类：`categories_json.php?advanced_search=true&term=...`；
- 艺术家：`models_json.php?q=...`，不得误用 `term`；
- 视频排序：`sort_by`；
- 内容取向：`flag1`；
- 上传时间：将设备当前日期减去所选相对周期，发送 `post_date_from=YYYY-MM-DD`；
- 时长：`duration_from` 与 `duration_to`，单位为秒；
- 已验证上传者：`flag2=1`；
- 标签、分类和艺术家：分别使用 `tag_ids`、`category_ids` 和 `model_ids`。

请求协议由本地接口文档、公开页面 HTML 和公开前端脚本交叉确认，不需要登录，也不使用真实账号凭据。

### 页面行为

- 输入至少两个字符后，并行获取标签、分类和艺术家建议；
- 过期自动补全结果通过 generation token 丢弃；
- 标签、分类和艺术家均可加入筛选，同类最多五项；
- 所有筛选以可见 `InputChip` 展示并可逐项删除；
- 手机筛选弹层限制为视口高度的 90%，内部滚动；
- 综合结果展示实体快捷入口和视频流，视频流接近底部时自动加载下一页；
- 初始页展示账号搜索历史和公开热门标签；
- 加载、空状态、失败、重试和下拉刷新继续复用统一 `VideoFeed`。

### Drift v3

新增 `search_histories`：

- 复合主键为 `user_id + normalized_query`；
- 外键指向 `user_accounts`，删除账号时级联清除；
- 同一账号的大小写变体归并，保留最后一次显示文本；
- 每个账号最多保存最近 20 条；
- 未登录时仓库不写入任何记录；
- 时间按 Drift 当前 Unix 秒存储精度归一化，并在同秒高频写入时单调递增，保证裁剪顺序稳定。

迁移使用生成的 `from2To3` step 创建新表，保留 v1、v2、v3 schema 快照。

## 验证

- API 请求适配器验证搜索分页及全部核心筛选参数；
- API 测试验证三类自动补全端点的参数差异；
- 数据库测试验证账号隔离、大小写去重、20 条上限和账号级联删除；
- Widget 测试验证未登录不落库、登录后历史与筛选形成真实闭环；
- 迁移测试验证 v1→v2、v1→v3、v2→v3，并验证 v2 账号、播放和下载数据不丢失；
- Flutter 静态分析和全部 36 条测试通过。

## 后续

1. 根据服务端能力评估实体结果的服务端分页；
2. 为搜索关键词和实体建议增加可选的离线索引；
3. 将用户常用筛选与内容设置联动，但继续保持账号历史和全局偏好职责分离。
