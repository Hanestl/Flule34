# ADR-0009：结构化发现目录与统一内容集合页

- 状态：已接受
- 日期：2026-07-24

## 背景

发现页原先只展示六个不可点击的占位入口，标签、分类、艺术家、频道、排行榜和随机探索均无法形成浏览闭环。站点对这些实体提供不同目录路径，但它们的详情最终都是可分页、可排序的视频集合。

## 决策

### 统一领域模型

- `DiscoveryKind` 描述标签、分类、艺术家和频道及其路径段；
- `ContentCollectionItem` 保存实体 ID、标题、规范化路径、缩略图和可用的视频总数；
- `DiscoveryDirectorySpec` 描述普通目录或排行榜目录；
- `VideoSort` 统一相关度、最新、最多观看、最高评分、最长和随机排序，并保存站点使用的 `sort_by` 参数。

这些模型不依赖具体页面，使搜索、发现、订阅和后续筛选可以共享同一组语义。

### 页面与路由

- 发现页的六个入口全部可用，不再展示“即将接入”；
- 标签、分类、艺术家和频道进入统一目录页，目录页支持加载、失败重试、空状态和本地名称筛选；
- 目录实体进入统一集合页，复用 `VideoFeed` 的自动分页和错误状态；
- 集合页可切换最新、最多观看、最高评分、最长和随机排序；
- 排行榜独立聚合热门视频、高评分视频和艺术家排行榜；
- 随机探索使用 `/latest-updates/?sort_by=pseudo_rand`，每次重新进入可获得新的结果集；
- 二级页面挂在根导航器上，不显示底部一级导航。

### HTML 解析边界

目录解析只接受与当前类型路径段匹配的链接，并使用规范化路径去重。标题依次取链接 `title`、图片 `alt`、容器标题和链接文本；缩略图兼容延迟加载属性；视频数量仅在页面明确提供时解析。

## 验证

- 脱敏 HTML fixture 验证目录实体解析、字段优先级和去重；
- 请求适配器验证目录路径、集合分页路径和 `sort_by` 参数；
- Widget 测试验证“发现 → 标签目录”的真实导航；
- Flutter 静态分析和全部 27 条测试通过。

## 后续

1. 让搜索页复用 `VideoSort` 和内容实体建议；
2. 根据真实页面 fixture 扩展目录统计、简介和关注状态；
3. 为超大目录评估服务端索引或本地可搜索索引，避免一次性渲染全部条目。
