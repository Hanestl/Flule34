# Flule34 1.3.0

1.3.0 是一次围绕浏览、筛选、播放列表、下载管理和全屏体验的完整迭代。

## 主要更新

- 新增账号播放列表，可创建、重命名、管理视频归属并连续播放；
- 支持顺序播放、列表循环、单集循环和更积极的下一集预缓存；
- 首页可在设置中切换单列或双列布局；
- 收藏、历史和本地分类库支持搜索与筛选；
- 修复订阅分页与艺术家、上传者头像补全；
- 支持识别网站提供的 2160P 视频源；
- 下载管理支持仅删除记录、清理失效记录及批量删除；
- 全屏进入和退出更加连贯，进入时默认隐藏控件，退出后恢复普通播放器控件；
- 默认播放清晰度调整为 1080P，并在不可用时自动向下回退；
- 精简界面文字、设置项和低价值说明；
- 项目开源协议改为 MIT License。

## 下载

本版本仅提供 Android ARM64 APK，适用于绝大多数现代 Android 手机和平板。

安装前建议校验 Release 中 `SHA256SUMS.txt` 提供的 SHA-256。
