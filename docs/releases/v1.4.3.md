# Flule34 1.4.3

1.4.3 改善订阅管理体验，让用户无需绕到视频详情页或上传者主页，也能直接取消不再需要的订阅。

## 主要更新

- 订阅卡片新增三点菜单，可直接取消订阅；
- 取消订阅前提供简短确认，避免误触；
- 操作成功后立即从当前订阅列表移除对应项目；
- 订阅详情页右上角新增取消订阅入口；
- 从详情页取消后返回订阅列表，列表状态会同步更新；
- 取消过程中显示加载状态并阻止重复操作；
- 支持已验证协议的上传者、艺术家和分类订阅；
- 补充取消订阅协议、列表交互和详情页入口的自动化测试。

## 下载

本版本仅提供 Android ARM64 APK，适用于绝大多数现代 Android 手机和平板。

从正式版或本轮测试包升级的用户均可直接覆盖安装；本版本 ARM64 `versionCode` 已递增至 `2018`。

安装前建议校验 Release 中 `SHA256SUMS.txt` 提供的 SHA-256。
