# Flule34 1.4.0

1.4.0 重点重构订阅动态与视频集合体验，让大规模订阅、内容查找和长页面浏览更完整、更流畅。

## 主要更新

- 首页“关注”改为扫描全部艺术家与上传者订阅，合并去重后按发布时间全局排序，不再只展示少数订阅源；
- 首页关注与订阅页“最近更新”共用订阅动态索引，复用请求和本地快照，减少重复流量与等待；
- 修复订阅刷新偶发变为空白、无法继续下拉刷新的问题，并增强单个订阅源失败时的容错；
- “视频布局”设置扩展到首页、收藏、历史、搜索结果、本地分类库、播放列表和作者视频等全部视频列表；
- 新增独立的“订阅页布局”设置，默认使用信息密度更高的两列布局；
- 订阅作者与上传者的视频页面新增搜索和筛选，便于在大量作品中快速定位内容；
- 长页面下滑超过一屏后显示回到顶部按钮，可平滑返回页面顶部；
- 统一搜索框、卡片、圆角和表面颜色，浅色与深色模式下的界面更简约、柔和、协调；
- 预测加载接入订阅动态快照，在前台操作优先的前提下提前准备可能访问的内容。

## 下载

本版本仅提供 Android ARM64 APK，适用于绝大多数现代 Android 手机和平板。

从测试包升级的用户也可直接覆盖安装；本版本 ARM64 `versionCode` 已递增至 `2009`。

安装前建议校验 Release 中 `SHA256SUMS.txt` 提供的 SHA-256。
