# Flule34 1.5.0

1.5.0 是 Flule34 的完整中文化版本，同时集中完善搜索、视频卡片、播放器、诊断日志、数据升级和长期运行可靠性。此说明覆盖自 1.4.5 以来的全部公开变化。

## 中文翻译基础

- 内置 8,090 个标签译文和 1,898 个分类译文；标签与分类使用独立词表，分类专用译文优先；
- 标题不批量内置，由用户手动填写或翻译服务按需翻译，避免为用户永远看不到的视频预生成大量数据；
- 标题、分类、标签可以分别选择“原文 / 中文 / 双语”，三者默认均为双语；缺少译文时会可靠回退原文；
- 双语显示不再使用括号拼接，而是使用贯穿当前文字行高的浅色 UI 分隔线；
- 标签、分类和标题均允许自然换行，不限制为一行或两行；双列视频卡片使用瀑布流，左右卡片可以按各自内容高度排列；
- 用户译文优先级最高；API 已学习译文作为长期本地数据保存，新内置词表不会覆盖用户已经获得的 API 译文；
- 内置词表只更新原本就属于内置层的内容，不覆盖用户手动译文、API 译文或翻译服务配置。

## 手动编辑与中文翻译库

- 长按标题所在的完整信息区、分类或标签即可新增或编辑中文译文；即使当前只有原文，也能直接进入编辑；
- 编辑框上方显示英文原文，下方提供可修改的中文结果，并可恢复到非用户覆盖层；
- 视频卡片中从封面底边到卡片底边的实际信息区均可触发标题编辑，包括标题、发布时间、评分、浏览量及其内边距；封面长按仍只负责视频预览；
- “中文翻译库”统一展示内置、API 与用户三层译文，可按标题、分类、标签及来源筛选；
- 支持按最近更新、原文、中文和来源排序，并支持关键词搜索、单项编辑、来源级批量选择和批量删除；
- “最近更新”会把有真实更新时间的用户/API 译文排在无时间戳的纯内置词条之前；
- 批量删除 API 译文使用数据库事务和按类型批量语句，不再逐条刷新界面；用户译文不会被一并删除；
- 翻译库可导出版本化 JSON：导出包含内置、API 和用户三层；
- 导入只接收 API 与用户层，明确忽略文件中的内置层，并提供“安全合并”和“导入文件优先”两种模式；
- 翻译库文件不包含 API Key、Cookie、账号密码或翻译服务配置。

## 翻译服务

- 可以新建多个翻译服务、启停、复制和排序；上方服务失败后会自动尝试下一项；
- 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、DeepL 和 MyMemory；
- 三种 AI 协议默认提供对应的 DeepSeek 基址；API Key 位于模型名前方，模型既可手动填写，也可从当前基址和 Key 拉取列表选择；
- DeepL 与 MyMemory 使用固定官方基址并提供官网入口；DeepL 明确区分 `API Developer / API Free` 和 `API Growth / API Pro` 端点；
- 长按整张服务卡片即可拖拽排序；三点菜单提供编辑、复制和删除，复制项会插入原服务下一位；
- 服务卡片只显示名称和接口类型，不再显示冗余优先级文字；编辑器宽度固定，不因基址、错误提示或协议切换而横向跳变；
- AI 每次只接收当前一个标题、标签或分类，不会把整段视频资料、艺术家或上传者一起发送；
- AI 提示词明确成人视频翻译语境和三类内容规则：标签、分类尽量简短，标题自然通顺且不添加信息；
- 人名、角色名和作品名优先使用通行中文名，没有通行译名时尽量自然音译；
- 作者、画师、制作方及其他创作者署名保持原文，标题末尾的 `by`、破折号、括号或方括号署名不翻译；
- 成人术语在含义明确且有自然中文表达时准确翻译，同时允许 `3D`、`VR`、`POV` 等数字、技术术语和通用缩写保留原文；
- DeepL 使用成人视频领域上下文和标题、分类、标签专用 `custom_instructions`，请求体采用官方支持的字符串数组格式；
- 每个 AI 服务首次调用时会依次尝试关闭思考、最低思考和默认行为；成功策略按“服务 ID + 协议 + 基址 + 模型”持久化，后续请求不再重复试探；
- 如果所有思考控制参数均不兼容，会固定为不传思考参数，由服务采用默认行为；修改协议、基址或模型后才重新探测；
- 自动翻译按标题、分类、标签分别勾选，默认全部关闭；仅在缺少本地译文且存在可用服务时请求并长期保存结果；
- 翻译设置增加长按编辑提示，并明确建议优先使用更自然、准确的 AI 翻译。

## 中文搜索

- 搜索页支持中文标签反查，匹配内置译名和用户译名；显示采用用户译文优先，但搜索仍同时接受用户与内置别名；
- 选择中文标签建议后，仍使用对应英文标签执行网站筛选；
- 中文标题搜索会同时执行网站原生关键词搜索和本地已学习标题反查，再按视频去重合并；
- 标题反查覆盖用户手动译文和 API 已学习译文，为未来扩大标题翻译范围保留数据基础；
- 没有对应中文标签或已学习标题时会显示明确空状态。

## 视频卡片与界面

- 视频标题不再限制行数，卡片高度由完整标题和元数据自然决定；
- 双列布局改为瀑布流，缩小屏幕边缘、卡片之间和封面之间的空隙，并减小卡片圆角；
- 双语标签和分类卡片可增长为两行或更多行，不再裁掉末尾文字；
- 视频布局设置变化会立即作用于首页和媒体库，无需先切换页签；
- 翻译设置中的显示模式拆分为标题、分类、标签三组；自动翻译改为可扩展的独立复选项；
- 翻译库的类型、来源和排序集中到右上角筛选入口；
- 翻译服务拖拽取消突兀的按压反色和错位外框，并避免拖动结束瞬间闪色；
- 视频详情简介恢复正常的文本选择边界拖动，并可在选择区域之外点击取消；
- 从收藏列表进入详情页会保留已确认收藏状态，按钮正确显示“已收藏”。

## 播放器

- 播放过程中长按画面 500ms 进入临时 2 倍速，松手后恢复长按前速度；
- 临时倍速期间锁定其他画面手势，不会被水平进度拖动、垂直音量或亮度手势接管；
- 画面上方使用三个低调的右向三角形依次明灭提示临时倍速；
- 再缓冲时在画面中央显示传统圆形加载指示器，并只在播放器已经初始化且仍有播放意图时出现；
- 本地固定 `better_player_plus 1.3.4` 源码，修复播放位置定时查询与播放器释放/切换竞态造成的 Android JNI 致命闪退；
- 为 Dart 位置轮询、释放流程和 Android MethodChannel 增加异常边界，减少播放器切换和退出时的未处理异常；
- 视频源自动刷新限制为最多 3 次，Cookie、seek 或刷新失败后恢复到可操作状态，不再无限加载；
- 播放进度、缓存区间和缓冲状态使用更稳定的独立更新路径。

## 日志、隐私与数据

- 新增本地诊断日志，仅保存在设备，不集成第三方崩溃上报，也不会自动上传；
- 日志写入前自动脱敏 Cookie、授权头、媒体令牌、账号字段等敏感信息；
- 日志最多保留 7 天，单日上限 2 MB、总计上限 10 MB；
- “隐私与数据”支持导出最近日志和诊断信息，也可一次清除全部应用日志；
- 错误日志保留足够完整的异常和调用栈，便于 Release 符号化，不再只保留约 600 字符；
- 自动翻译默认关闭；艺术家、上传者、model 和频道不会进入翻译请求；
- API Key 使用本地安全凭据存储，翻译导出文件和日志均不包含密钥。

## 数据升级与可靠性

- 数据库升级到 v12，新增用户译文和 API 已学习译文表，并为播放进度、下载任务和搜索历史增加高频索引；
- 升级迁移保留账号、Cookie、本地分类库、精选库、播放列表、收藏状态、下载记录、播放进度、搜索历史和全部翻译数据；
- 精选库清单更新时，同名现有库不会被覆盖；相同视频跳过，新增视频进入独立增量库；
- 会话恢复使用单飞保护，失效凭据不再递归触发登录，并发请求只执行一次恢复；
- 关注流扫描和分页串行提交，避免丢页、回退或旧快照覆盖新状态；
- 下载事件按到达顺序处理，增加重复入队保护、启动任务对账、迟到回调隔离和未知总大小进度保护；
- 下拉刷新会等待重叠加载完成，不再静默忽略；播放列表筛选最多自动读取 5 页；
- 标签、分类和艺术家建议增加 300ms 防抖和竞态保护；
- 翻译服务初始化失败可在本次运行中重试，保存、复制、删除和模型拉取失败均有明确反馈；
- 订阅头像首次失败后允许重试，并处理异常缩略图地址。

## 下载与升级

- 本版本仅提供 Android ARM64 APK，适用于绝大多数现代 Android 手机和平板；
- 正式 APK 的 `versionCode` 为 `2027`，可从 1.4.5 正式版及本轮测试包直接覆盖安装；
- 版本显示为 `1.5.0`，GitHub 标签为 `v1.5.0`；
- 安装前可使用 Release 中的 `SHA256SUMS.txt` 校验 APK 完整性。
