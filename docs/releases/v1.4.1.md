# Flule34 1.4.1

1.4.1 新增轻量的视频预览能力，帮助用户在进入播放页面前更快判断视频内容，同时保持列表浏览和播放列表跳转的一致性。

## 主要更新

- 长按视频卡片约一秒，可在当前页面底部播放静音视频预览；
- 预览支持封面、标题和元数据区域，列表滚动时会自然取消长按识别；
- 预览窗口自动避让底部导航栏，点击窗口外区域或返回即可关闭；
- 点击预览画面会执行原视频卡片的打开行为，普通列表进入视频详情，播放列表继续进入专属播放页面；
- “播放设置”新增“视频预览”开关，默认开启，可按需关闭；
- 本地分类库中的旧视频索引可按需补全预览地址，并将有效结果保存在本机；
- 新增预览地址失效恢复机制，失效缓存会自动清理并重新解析；
- 相关视频预览保持静音，不会暂停详情页顶部正在播放的视频；
- 本地数据库升级至第 7 版，安全迁移并保存本地分类库视频的预览地址。

## 下载

本版本仅提供 Android ARM64 APK，适用于绝大多数现代 Android 手机和平板。

从正式版或本轮测试包升级的用户均可直接覆盖安装；本版本 ARM64 `versionCode` 已递增至 `2012`。

安装前建议校验 Release 中 `SHA256SUMS.txt` 提供的 SHA-256。
