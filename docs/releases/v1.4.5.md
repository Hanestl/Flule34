# Flule34 1.4.5

1.4.5 重点改善播放器错误恢复、播放列表连播稳定性以及长时间使用时的缓存与存储效率。

## 主要更新

- 视频源失败且地址刷新也失败后，再次触发失败会正确退出加载状态并提供重试，不再永久转圈；
- 播放列表自动连播加载下一页失败时会明确提示，并允许用户再次尝试；
- 修复 `1920x1080`、`1920×1080` 等视频源标签可能把宽度误认为高度的问题；
- 隐私与数据页面只保留一个搜索历史清理入口；
- 关注流一次翻页只保存一次本地快照，减少重复存储写入；
- 视频详情和视频分页缓存增加过期清理与容量限制；
- 播放器进度变化不再引起整个播放器页面重建；
- 订阅和播放列表分页会容忍偶发重复页，并在连续多页无新增时停止；
- 已彻底删除停用的日志框架及空日志调用，升级时仍会清理旧版本残留的调试数据；
- 损坏的订阅活动快照现在会真正从本地设置中删除。

## 下载

本版本仅提供 Android ARM64 APK，适用于绝大多数现代 Android 手机和平板。

从正式版或测试包升级均可直接覆盖安装；本版本 ARM64 `versionCode` 已递增至 `2020`。

安装前建议校验 Release 中 `SHA256SUMS.txt` 提供的 SHA-256。
