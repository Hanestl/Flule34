# Flule34 1.3.1

1.3.1 重点改善大规模订阅管理、播放器手势与页面打开速度。

## 主要更新

- 修复订阅较多时只能显示首批 14～15 项的问题，支持完整异步分页；
- 订阅支持搜索，并可按名称、最新订阅或最近更新排序；
- 播放列表和本地分类库支持搜索与排序，播放列表内部也可搜索和筛选视频；
- 全屏播放器新增锁定按钮，锁定后隐藏控件并停用播放器手势；
- 全屏和非全屏播放器均支持双击播放或暂停、横滑调整进度、纵滑调整系统媒体音量；
- 横滑时进度点实时跟随，进度条会加粗以提供明确反馈；
- 新增可取消的预测性加载，在空闲时准备收藏、历史、播放列表、订阅及可能打开的视频详情；
- 当前台请求到来时自动让出资源，并复用相同的在途请求，减少页面打开后的等待；
- 收藏与历史加入按账号隔离的短期缓存，刷新时保留已有内容，降低空白等待感。

## 下载

本版本仅提供 Android ARM64 APK，适用于绝大多数现代 Android 手机和平板。

安装前建议校验 Release 中 `SHA256SUMS.txt` 提供的 SHA-256。
