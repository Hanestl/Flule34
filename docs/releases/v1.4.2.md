# Flule34 1.4.2

1.4.2 集中改善下载管理的可控性与稳定性，解决多任务进度更新导致列表跳动、暂停后进度归零，以及播放已下载文件时卡片底部闪动的问题。

## 主要更新

- 下载列表改为按任务创建时间稳定排列，进度更新不再让多个任务轮流置顶；
- 下载中的任务新增暂停和继续操作，暂停后保留已完成进度；
- 已取消、失败或文件不存在的任务可直接重新下载；
- 移除不可恢复的下载取消入口，避免任务从下载页消失后无法继续；
- 下载任务操作区保持固定高度，播放本地文件时卡片底边不再跳动或闪烁；
- 下载设置合并为一个清晰的“下载清晰度”选项，可选择每次询问、最高可用或指定分辨率；
- 兼容旧版下载设置，升级后无需重新配置；
- 补充下载状态、数据库排序与设置迁移的自动化测试。

## 下载

本版本仅提供 Android ARM64 APK，适用于绝大多数现代 Android 手机和平板。

从正式版或本轮测试包升级的用户均可直接覆盖安装；本版本 ARM64 `versionCode` 已递增至 `2016`。

安装前建议校验 Release 中 `SHA256SUMS.txt` 提供的 SHA-256。
