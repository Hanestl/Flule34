# Flule34 1.4.4

1.4.4 重点改善播放进度的可靠性、设备级续播体验、下载启动反馈与后台通知隐私。

## 主要更新

- 播放进度改为设备级本地数据，无需登录即可保存和恢复；
- 登录、退出或切换账号不再影响已有播放进度；
- 从旧版本升级时自动合并同一视频的账号进度，并保留最近更新的一条；
- 关闭“记忆播放进度”时会确认并彻底清除全部本地记录；
- 续播和手动跳转会校验播放器真实位置，失败时自动重试或回退，不再出现画面与进度条分离；
- 下载建立连接时明确显示“正在连接”，有效数据到达后再显示真实进度；
- 下载连接异常能够更快进入重试与恢复流程；
- 置顶按钮不再遮挡筛选菜单、底部弹窗或对话框；
- 后台下载与播放通知使用通用隐私文案，不显示视频标题、作者、封面、文件名或清晰度；
- 下载任务合并为一个运行通知，完成、失败、暂停和取消不再额外打扰。

## 下载

本版本仅提供 Android ARM64 APK，适用于绝大多数现代 Android 手机和平板。

从正式版或测试包升级均可直接覆盖安装；本版本 ARM64 `versionCode` 已递增至 `2019`。

安装前建议校验 Release 中 `SHA256SUMS.txt` 提供的 SHA-256。
